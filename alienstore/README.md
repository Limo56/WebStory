# ИНОПЛАНЕТНЫЙ МАГАЗИН

Переделка сайта инопланетян из GSGW
## Как открыть

Просто дважды кликните `index.html`. Для проверки на телефоне удобнее локальный сервер:

```
py -m http.server 8000
```

и открыть `http://localhost:8000`.

## Структура

```
index.html        разметка страницы
style.css         все стили
app.js            корзина, счётчик посещений, переключатель мигания
img/*.gif         картинки товаров и фавикон
```

## Как добавить товар

Скопируйте любой блок `<div class="product">` в `index.html` и поменяйте:

- `src` картинки;
- название и описание;
- цену в `.product-price`;
- три атрибута у кнопки — `data-add` (уникальный id), `data-name`, `data-price`.

Всё остальное (корзина, суммы, количество) подхватится само.

## Как это работает

- Корзина живёт в `localStorage` под ключом `megamagazin_cart_2001`, поэтому не пропадает
  при перезагрузке. # вообще оно энивей пропадает, так что мдэ...
- «Оформить заказ» ничего не отправляет: показывает номер заказа и очищает корзину.
  Если нужен настоящий приём заказов — сюда вешается запрос к Formspree / своему бэкенду.
- Счётчик посещений тоже на `localStorage`, стартует с 847.
- Кнопка «Отключить мигание» в подвале снимает CSS-анимацию `.blink`. # я ее убрал, но функция в скрипте осталась
  Если у пользователя в системе включено «уменьшение движения», мигание отключено сразу.


## Осторожно

- Мигание сделано с частотой 1 Гц — это безопасно. Не ускоряйте его выше 3 Гц.
- Звук не подключён специально: автоплей браузеры всё равно заблокируют.
  Если добавляете MIDI — только по клику.
